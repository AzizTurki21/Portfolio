# Aziz Turki — Portfolio

Responsive personal portfolio built with plain HTML, CSS and JavaScript.

## Included
- Main hero portrait (`assets/images/aziz-turki.jpg`)
- About, engineering projects, creative/video-editing section
- Education and experience timeline
- Skills, social links and responsive mobile navigation
- Scroll reveal animations and reduced-motion support

## Run locally
Open `index.html` in a browser, or run:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Before publishing
- Review and verify all project descriptions and dates.
- Add real project screenshots, repository links and the video showreel.
- Add an up-to-date CV PDF if you want a download button.
- Check the contact and social links.

## GitHub Pages
Upload the contents of this folder to the root of your `Portfolio` repository, then enable **Settings → Pages → Deploy from a branch → main / root**.
